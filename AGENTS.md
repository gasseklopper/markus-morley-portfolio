# Repository Instructions

This is a Qwik / Qwik City project.

## Qwik

For any implementation, refactor, debugging or review involving Qwik or Qwik City:

Use the `$qwik-web-framework` skill.

Follow the Qwik patterns defined by that skill instead of applying React conventions by default.

## Verification

Before finishing code changes:

- run the existing typecheck
- run lint
- run relevant tests
- report any checks that could not be executed
